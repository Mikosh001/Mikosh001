### 03 / Кодтың артындағы тәжірибе

- **Пайдалы AI.** Құжаттарды салыстыру, диалог арқылы жаттығу және экологиялық симуляция.
- **Толық өнім.** Интерфейс, API, деректер және интеграциялар бір жүйеде.
- **Командалық жұмыс.** Хакатон MVP-лері, жылдам жетілдіру және түсінікті техникалық құжаттама.

<details>
<summary><b>Жобалардағы жеке үлесім</b></summary>

- **Qurylym AI:** OpenAI API интеграциясы, промпттар мен талдау логикасы, техникалық құжаттама және frontend/backend/AI модульдерін біріктіру.
- **TOLQYN AI:** экологиялық мониторинг MVP-і, картадағы дрейф симуляциясы, бастапқы көзді кері есептеу, OpenCV талдауы және офлайн демо.
- **SpeakSpace:** команданың техникалық тапсырмасы бойынша MVP кодын әзірлеу және рөлдік диалогтарды Gemini AI-мен байланыстыру.
- **Finance Tracker:** finance_service.py және report_service.py модульдері: транзакциялар, баланс, санаттық шығындар, айлық есеп және бюджет лимиттері.
